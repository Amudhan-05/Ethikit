open-source ethical-AI evaluation

Ethikit Docs

An orchestrator that runs real fairness, explainability, privacy, and robustness checks against your models and shows the trade-offs, so you can select a model and audit the choice — it is a selection-and-audit tool, not a ranker, and never pretends there is one "most ethical" score.

Console

The live, terminal-style UI: pick data, models, tools and weights; watch the run flow through every tool by principle; inspect the maths behind each number; attach a governance checklist to the model cards. Here it replays a recorded run; run python -m ethikit serve to use it on your own data.
