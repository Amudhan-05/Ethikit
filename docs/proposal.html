Ethikit: model selection &
audit on ethical principles

Give it your dataset and your candidate models. It runs a battery of open-source checks and shows each model's profile across fairness, transparency, explainability, privacy, and safety — with the maths behind every number. It is not a ranker: it helps a person choose, and leaves an audit trail to justify the choice.

The problem, in one line

Teams pick models on accuracy alone. Whether a model is fair, explainable, private, and safe is checked late, by hand, with a scatter of different tools — if at all. Ethikit turns that scatter into one repeatable step.

One honest caveat, up front. There is no single "most ethical" model. Some fairness goals are mathematically impossible to satisfy at the same time. So ethikit never hides the trade-offs behind one number — it shows a full profile and lets you say what matters most.

The principles we measure against

We didn't invent these. We harmonised the published principle sets of four bodies — UNESCO, Microsoft, IBM, and Google — into one shared checklist. Every check maps back to one of these.

The open-source tools, and what each one looks at

The trick to reading these checks: each tool inspects a different part of the system — the data, the model's insides, its predictions, or how it behaves under stress.

PrincipleOpen-source toolsWhat it inspects
Fairness / InclusivenessFairlearn, AIF360, Giskard data predictions
ExplainabilitySHAP, LIME, InterpretML model internals predictions
Transparency / AccountabilityModel Card Toolkit, datasheets documentation
PrivacyTensorFlow Privacy, Opacus, Presidio data behavior
Safety & RobustnessGiskard, Adversarial Robustness Toolbox behavior

Giskard is the standout: one scan covers bias, robustness, and data leakage across every ML model type — and later extends to large language models. It's the natural long-term backbone.

How the orchestrator works

Everything is a pipeline. A dataset and models go in the left; a profile and audit trail come out the right. The clever part is the middle: every tool is wrapped behind the same plug, so adding a new one never changes anything downstream.

How it gets used

Compare models fairly

Pick the model for a lending or hiring task not just on accuracy, but on a full fairness & safety profile — with the trade-offs made visible.

Set a bar to ship

"Only ship models whose fairness gap is below 10%." The check runs automatically, like a test in your pipeline.

Answer "which family is best?"

Run across many datasets to learn whether tree-based, linear, or other models tend to be more ethical — with statistics to back it.

Produce an audit trail

Every run emits a shareable report / Model Card — the evidence a reviewer, regulator, or client can read.

Where it's going

Now (works today): tabular machine-learning models — classifiers across five families — scored on fairness, explainability, privacy, and safety, on real or synthetic data, with a live demo.

Next: test across many datasets with proper statistics; add deeper privacy and robustness attacks; generate standards-compliant Model Cards.

Later: the same framework extends to deep learning and large language models (bias, hallucination, red-teaming) — because every tool sits behind the same plug, the profile and audit trail stay the same; only the checks change.

Ethikit · open-source ethical-AI evaluation orchestrator · built on Fairlearn, AIF360, SHAP, Giskard and the UNESCO / Microsoft / IBM / Google principle frameworks. Runs on scikit-learn today; deep-learning and LLM support planned.
