Tool & principle coverage

Which registered tool addresses which principle above, and what it actually does internally to produce that signal -- so a score can always be traced back to a concrete mechanism instead of being read as a black box. Principles with more than one tool listed are corroborated from independent angles; principles with none have no registered evaluator yet (see ethikit/principles.py's tool_addressable flag). Per-model results carry their own run-specific mechanism text -- see each Model Card.

principle tool mechanism
explainability explainability Two independent, model-agnostic signals, both treating the model as a black-box predict()/predict_proba() function -- neither inspects real internal weights: (1) surrogate fidelity -- a depth-3 decision tree is trained to mimic the model's own predictions; how accurately that tiny, human-readable tree reproduces them is the fidelity score. (2) feature attribution -- when SHAP is installed, mean |SHAP value| per feature from a permutation-based explainer run over a random sample against a background sample; falls back to the surrogate tree's own feature_importances_ if SHAP errors or isn't installed.
fairness fairness Groups the model's test-set predictions by a declared sensitive attribute and compares outcomes across groups using fairlearn.metrics.MetricFrame (or the equivalent numpy computation if fairlearn isn't installed): for classification, selection rate (demographic parity) and TPR/FPR gap (equalized odds); for regression, MAE/MSE gap between groups, since selection rate isn't defined for a continuous target. Inspects PREDICTIONS only: it never looks at the model's weights or training process, so it can flag *that* a gap exists between groups but not *why*.
fairness giskard Runs Giskard's automated scanner over a random sample of test rows, treating the model as a black-box predict_proba function: PerformanceBiasDetector auto-discovers data slices via loss-guided slicing and flags ones whose performance metric is significantly worse than the global average (-> fairness); NumericalPerturbationDetector and EthicalBiasDetector perturb feature values (noise, rescaling, protected-attribute swaps) and flag high failure rates (-> safety). Issues are weighted by severity (major=3/medium=2/minor=1) and summed per principle bucket. Deliberately skips the data-leakage detector -- see this module's docstring.
inclusiveness fairness Groups the model's test-set predictions by a declared sensitive attribute and compares outcomes across groups using fairlearn.metrics.MetricFrame (or the equivalent numpy computation if fairlearn isn't installed): for classification, selection rate (demographic parity) and TPR/FPR gap (equalized odds); for regression, MAE/MSE gap between groups, since selection rate isn't defined for a continuous target. Inspects PREDICTIONS only: it never looks at the model's weights or training process, so it can flag *that* a gap exists between groups but not *why*.
privacy membership_inference Black-box membership-inference attack (Yeom et al. 2018 confidence/loss-threshold style -- the same feature-based approach TensorFlow Privacy's own attack module implements, run directly via scikit-learn since tensorflow-privacy has no Python-3.12-compatible release). Extracts a per-sample 'how well does the model fit this point' feature for the model's own training rows (known members) and held-out test rows (known non-members) -- confidence in the true class + log-loss for classification when predict_proba is available (else the weaker label-only correctness indicator), or negative squared/absolute error for regression. Balances member and non-member counts by subsampling, then fits a LogisticRegression attack classifier and scores it via k-fold out-of-fold prediction (so the attack's own accuracy is never inflated by testing on rows it trained on). Reports attack AUC and attack advantage (2*(accuracy-0.5), clipped at 0) -- 0 means the attack is no better than guessing from the class balance alone (no detectable membership leakage from this feature); higher means the model's outputs let an attacker tell training rows apart from held-out rows.
safety art_robustness Runs a real black-box adversarial evasion attack (HopSkipJump, Chen et al. 2019, via the Adversarial Robustness Toolbox) against the fitted model treated as a label-only oracle -- no gradients or model internals are used, matching how an external attacker would actually query a deployed model. Wraps the model in art.estimators.classification.SklearnClassifier, then for a small sample of correctly-classified test rows searches for the smallest L2 perturbation that flips the prediction, within a tight iteration/query budget kept low so a full model-zoo sweep finishes in reasonable time (see this module's docstring for measured per-model timings). Reports the fraction of attacked rows the search could NOT flip within budget (higher = more robust) and, among the ones it did flip, the median perturbation size needed (higher = the attacker needed a bigger, more detectable change -- also more robust). Complements the existing RobustnessEvaluator's random-noise stability check with a worst-case, adversarially-searched one.
safety drift_detection Manufactures a synthetic covariate shift by adding shift_scale x (per-feature training std) to every feature of the test set (simulating a deployment population that has systematically drifted from the training population), then runs Alibi Detect's TabularDrift (per-feature Kolmogorov-Smirnov test, Bonferroni-corrected across features, reference = training data) against both the shifted and the original (unshifted) test set. Scores the detector's own reliability on this dataset (did it correctly flag the shifted set as drifted AND correctly leave the unshifted set alone?) and separately measures how much the model's own held-out performance metric degrades once that shift is present.
safety giskard Runs Giskard's automated scanner over a random sample of test rows, treating the model as a black-box predict_proba function: PerformanceBiasDetector auto-discovers data slices via loss-guided slicing and flags ones whose performance metric is significantly worse than the global average (-> fairness); NumericalPerturbationDetector and EthicalBiasDetector perturb feature values (noise, rescaling, protected-attribute swaps) and flag high failure rates (-> safety). Issues are weighted by severity (major=3/medium=2/minor=1) and summed per principle bucket. Deliberately skips the data-leakage detector -- see this module's docstring.
safety robustness Adds Gaussian noise (sigma x per-feature standard deviation) to every numeric test feature, repeated several times, and measures the fraction of predictions that stay the same (classification) or the relative change in predicted value (regression). Inspects BEHAVIOR under input perturbation only -- it says nothing about *why* a model is or isn't stable, and never touches categorical/text features.
transparency explainability Two independent, model-agnostic signals, both treating the model as a black-box predict()/predict_proba() function -- neither inspects real internal weights: (1) surrogate fidelity -- a depth-3 decision tree is trained to mimic the model's own predictions; how accurately that tiny, human-readable tree reproduces them is the fidelity score. (2) feature attribution -- when SHAP is installed, mean |SHAP value| per feature from a permutation-based explainer run over a random sample against a background sample; falls back to the surrogate tree's own feature_importances_ if SHAP errors or isn't installed.
utility performance Standard scikit-learn metrics (accuracy/F1/ROC-AUC for classification, R2/RMSE/MAE for regression) computed by comparing the model's own predict()/predict_proba() output against the true labels on the held-out test set. Not an ethics evaluator -- provides the utility axis every trade-off in the profile is measured against.
Scores are relative within this run. Ethics is multi-dimensional and context-dependent: use this as evidence for human judgement, not a verdict. Governance principles (accountability, human oversight, well-being) are not captured by these metrics.
