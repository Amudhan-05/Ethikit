ethikit in five steps

What it is: model selection and audit on ethical principles. Not a ranker, not a single ethics score.

#StepWhat it doesWhere in the codeConsole / CLI
1FrameData, target, sensitive column, candidate models → one run configsession.prepare()configure panel · ethikit run
2Train & predictFit on train split; predict held-out test; results belong to model + datarun_benchmark()log: fit
3Tools by principleEach Evaluator declares principle + inspected part; several tools per principleevaluators/*, coverage.pyflow graph middle column
4ProfileMetrics → 0–1 (relative to this run) → per-principle profile → Pareto front; weights optionalscoring/aggregate.pyresults tab · --weights
5Audit trailFormula, worked numbers, intermediate tables, model card, governance checklistdetails["trace"], model_card.py, checklists.pyinspect · model-card · governance tabs
Say it: "ethikit helps you pick a model on your own data, and shows its working so someone else can check the pick."
Limits to own up to: scores are relative within a run; the cross-dataset suite is generic (not per-domain, no sensitive attribute); governance checklists are evidence, not scores.
