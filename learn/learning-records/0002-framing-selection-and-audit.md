# Project framing: model selection and audit, not a ranker

Learner explicitly asked that the project be framed as model selection and audit on ethical principles, not model ranking, and asked whether the cross-dataset step is per-domain (it is not: generic PMLB suite, no sensitive attribute). Teach both claims, and teach where the limits are.

**Implications:** lessons must never describe ethikit as ranking models or crowning a "best" model.
