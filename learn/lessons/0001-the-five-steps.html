The five steps

Today's win: say, in order and in one breath, what each of ethikit's five steps does, and why the last step is the point of the project.

The idea in one line

ethikit is a model-selection and audit tool. You bring data and candidate models; it measures each model against ethical principles with open-source tools; a human picks — and can show why.

The five steps

1

Frame the decision

You supply a dataset, a target to predict, which column marks the sensitive groups (e.g. sex, or age split at 25), and the candidate models. Everything is one run config — the console's buttons and the ethikit run flags build the same thing.

code: ethikit/session.py → prepare()
2

Train and predict, on your data

Each model is fitted on the training split and asked to predict the held-out test split. Every later tool inspects those predictions or probes the model — so the result belongs to this model on this data, not to the model in the abstract.

code: ethikit/benchmark/runner.py → run_benchmark()
3

Tools, grouped by principle

Each tool is an Evaluator that declares which principle it speaks to (fairness, privacy, safety…) and which part of the system it inspects (data, predictions, internals, behaviour). Several tools can serve one principle — a second opinion. The console's flow graph shows exactly this step happening live.

code: ethikit/evaluators/base.py; ethikit/coverage.py
4

Standardise into a profile

Every metric is rescaled to 0–1 (1 = best among your candidates), then averaged per principle into a profile. The Pareto front keeps the models nobody beats on every principle at once. A single ordering appears only if you give weights.

code: ethikit/scoring/aggregate.py
5

Leave an audit trail

For every number: the formula, the same formula worked with this run's values, the intermediate tables behind it, and the model card. For principles no tool can measure (accountability, human oversight, well-being), you answer a governance checklist and it rides along on the card.

code: details["trace"] in each evaluator; ethikit/report/model_card.py; ethikit/checklists.py
A limit to say out loud. Step 4's 0–1 scores are relative to the models in your run. They tell you which candidate is better here, not that any is "good enough". That is why step 5 exists.

Read the one primary source

Fairlearn — Common fairness metrics: it defines demographic parity as the gap between the highest and lowest group selection rates, and warns that achieving it does not by itself mean a classifier is fair. That warning is the reason ethikit shows trade-offs instead of one score.
